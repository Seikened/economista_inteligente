Enfoque del proyecto

Datos, lenguaje y mercados: un solo sistema.

El análisis de sentimientos en noticias financieras es una señal econométrica emergente. Este proyecto construye la infraestructura completa para capturar, clasificar y correlacionar ese sentimiento con los retornos reales de las acciones más grandes del mundo.

01 Módulos del Sistema
Módulo Responsabilidad Tecnología Estado
director.py Orquestador del pipeline completo EmpresasDirectory Activo
get_noticias.py Fetch de noticias con paginación Finnhub API · yfinance Activo
cliente_clasificador.py Carga, filtrado y clasificación por ticker Polars · Parquet Activo
modelo_clasificador.py Inferencia NLP con promedio ponderado FinBERT · HuggingFace · PyTorch Activo
modelo_matematico/ Modelos econométricos y ratios financieros Rich · Matplotlib En progreso
02 Áreas del Proyecto
📰
Recopilación de Noticias
  • Finnhub API con paginación automática
  • Enriquecimiento con precios desde yfinance
  • Cache local en noticias.json
🧠
Análisis de Sentimientos
  • Modelo FinBERT (ProsusAI/finbert)
  • Clasificación de titular + resumen con peso
  • Salida: Positivo · Negativo · Neutral
📈
Datos de Mercado
  • 19 tickers tecnológicos de gran capitalización
  • Precios históricos y retornos calculados
  • Merge con datos de sentimiento por fecha
📊
Visualización y Análisis
  • Gráficas por ticker en data/graficas/
  • Ratios financieros con tablas Rich
  • Parquet como capa de cache analítico

Propósito del proyecto

Texto, números
y mercados.

El lenguaje es datos. Las noticias financieras contienen señales que los modelos econométricos tradicionales no capturan. Este sistema cierra esa brecha: desde una API pública hasta un análisis cuantitativo reproducible.
