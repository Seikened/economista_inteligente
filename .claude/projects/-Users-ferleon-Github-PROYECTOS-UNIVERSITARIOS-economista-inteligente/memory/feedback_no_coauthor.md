No agregar la línea `Co-Authored-By: Claude` en los commits de este proyecto.

**Why:** El usuario no quiere que aparezca Claude como co-autor — interfiere con sus planes.
**How to apply:** Al hacer commits, omitir la línea Co-Authored-By completamente.
